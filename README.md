# Сайт-портфолио Яши Кадырова

Одностраничный сайт видеомонтажёра: главный экран, «Обо мне», навыки, работы с фильтром и просмотром, опыт, контакты. Внизу экрана — навигация в виде монтажного таймлайна: клипы — это разделы, плейхед показывает, где вы находитесь.

Сайт написан на чистом HTML, CSS и JavaScript. Сборка и установка зависимостей не нужны.

## Что где лежит

```
index.html            разметка и все тексты
404.html              страница «не найдено»
css/style.css         оформление (цвета и шрифты — в начале файла, блок :root)
js/data.js            контакты и список работ — этот файл вы будете менять чаще всего
js/main.js            логика: работы, фильтр, просмотр, таймлайн, анимации
assets/img/           портрет, обложки, картинка для превью ссылок (og.jpg), иконки
assets/video/         свои видеофайлы, которые играют прямо на сайте
favicon.svg           иконка вкладки
robots.txt, .nojekyll служебные файлы для хостинга
```

## Как запустить на своём компьютере

Самый простой способ — дважды щёлкнуть `index.html`, сайт откроется в браузере.

Чтобы всё работало точно как на хостинге, запустите локальный сервер. В папке проекта откройте терминал и выполните:

```
python -m http.server 8000
```

Затем откройте в браузере `http://localhost:8000`. Если Python не установлен, подойдёт расширение Live Server для VS Code.

## Как менять содержимое

**Добавить работу.** Откройте `js/data.js`, в список `projects` добавьте блок:

```js
{
  title: "Название ролика",
  category: "edit",              // id категории из списка categories в том же файле
  role: "Монтаж, графика, звук",
  text: "Пара слов о задаче и результате",
  youtube: "XXXXXXXXXXX"         // ID ролика: то, что в ссылке после watch?v=
}
```

Ролик с `youtube` открывается прямо на сайте, обложка берётся с YouTube сама. Для работы без видео укажите `image` (путь к картинке в `assets/img/`) и `link` (ссылка на оригинал). Поле `wide: true` делает карточку крупной.

**Новая категория.** Добавьте строку в `categories` в том же файле и используйте её `id` в работах. Кнопка фильтра появится сама.

**Контакты.** Там же, в блоке `contacts`. Впишите ник Telegram, ссылки на YouTube и Instagram — кнопки появятся автоматически. Пустая строка скрывает кнопку.

**Тексты разделов** — в `index.html`, каждый раздел подписан комментарием.

**Портрет** — замените файл `assets/img/portrait.jpg` (вертикальный кадр, от 800 px по ширине).

## Публикация: GitHub Pages

Для этого сайта GitHub Pages подходит лучше всего: сборка не нужна, достаточно загрузить файлы. Аккаунт GitHub бесплатный.

### Способ без терминала

1. Зарегистрируйтесь на github.com.
2. Нажмите **New repository**. Имя — например `portfolio`. Видимость — **Public** (на бесплатном тарифе Pages работает только с публичными репозиториями). Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите в окно всё содержимое папки проекта (не саму папку, а файлы и папки внутри неё). Нажмите **Commit changes**.
   Файл `.nojekyll` может быть скрыт в проводнике — включите показ скрытых файлов. Если он не загрузится, сайт всё равно будет работать.
4. Откройте **Settings → Pages**. В блоке **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main**, папку **/(root)**. Нажмите **Save**.
5. Через 1–2 минуты на той же странице появится адрес: `https://ВАШ_ЛОГИН.github.io/portfolio/`.

Чтобы адрес был короче — `https://ВАШ_ЛОГИН.github.io/` — назовите репозиторий `ВАШ_ЛОГИН.github.io`.

### Способ через Git

```
cd путь/к/папке/проекта
git init
git add .
git commit -m "Сайт-портфолио"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/portfolio.git
git push -u origin main
```

После этого выполните шаги 4–5 из способа выше.

### После публикации

В `index.html` замените `https://example.com/` на адрес вашего сайта в четырёх местах: `canonical`, `og:url`, `og:image`. Без этого картинка-превью не подтянется, когда вы отправите ссылку в Telegram или WhatsApp. Проверить превью можно через бота @WebpageBot в Telegram.

### Как обновлять сайт

- Через сайт GitHub: откройте файл в репозитории, нажмите на карандаш, внесите правки, **Commit changes**. Новые файлы — **Add file → Upload files**.
- Через Git: `git add .`, `git commit -m "что изменили"`, `git push`.

Изменения появляются на сайте через 1–2 минуты. Если не видно — обновите страницу с Ctrl+F5.

После правок в `css/style.css`, `js/data.js` или `js/main.js` увеличьте число в `?v=4` в `index.html` (три места: одна ссылка на стили и две на скрипты). Тогда браузеры посетителей сразу возьмут новые файлы, а не смесь старых и новых.

### Ограничения бесплатного GitHub Pages

- Сайт — не больше 1 ГБ, трафик — до 100 ГБ в месяц, до 10 обновлений в час. Для портфолио это с большим запасом.
- Репозиторий должен быть публичным: исходники сайта видны всем.
- Только статические файлы. Видео в репозиторий загружать не стоит: храните ролики на YouTube или Vimeo и вставляйте по ID.

## Другие бесплатные хостинги

| Сервис | Когда выбирать | Что учесть |
|---|---|---|
| Cloudflare Pages | Нужен безлимитный трафик или приватный репозиторий | 500 публикаций в месяц, до 20 000 файлов, файл до 25 МБ. Адрес вида `имя.pages.dev` |
| Netlify | Хочется загрузить сайт перетаскиванием папки, без GitHub | Бесплатно 300 кредитов в месяц; когда они заканчиваются, сайт ставится на паузу до следующего месяца |
| Vercel | Если позже перейдёте на Next.js | Бесплатный тариф Hobby — только для некоммерческого использования; сайт, через который вы ищете заказы, формально под это не подходит |

Подключение у всех одинаковое: зарегистрироваться, выбрать репозиторий с GitHub, оставить поле команды сборки пустым, папка публикации — корень проекта.

## Свой домен

Подключить собственный домен можно бесплатно на всех четырёх сервисах, HTTPS-сертификат выдаётся автоматически. Но сам домен бесплатным не бывает: его покупают у регистратора и продлевают раз в год. Зона `.kz` покупается у казахстанских регистраторов, `.com` и другие международные зоны — у любого крупного (Cloudflare Registrar, Namecheap, Porkbun).

Бесплатные варианты:

- Оставить адрес хостинга: `логин.github.io` или `имя.pages.dev`. Для портфолио это нормально выглядит, особенно если логин — ваше имя.
- Если вы студент — GitHub Student Developer Pack даёт домен на первый год.

Подключение домена к GitHub Pages: **Settings → Pages → Custom domain**, вписать домен, затем у регистратора добавить DNS-записи, которые покажет GitHub, и включить **Enforce HTTPS**.

2. **Собрать шоурил на 45–60 секунд** и поставить его первой крупной карточкой.
3. **Показать «до и после»**: исходник и готовый кадр для цветокоррекции, графики или VFX.

6. **Заменить портрет** на кадр в хорошем разрешении, лучше за работой.
7. **Обновлять счётчики просмотров** в подписях к роликам раз в несколько месяцев — они вписаны вручную.
8. **Сделать английскую версию**, если планируете работать с зарубежными клиентами.
9. **Подключить бесплатную аналитику** (Cloudflare Web Analytics или Яндекс Метрика), чтобы видеть, какие работы открывают.
